## Dia 06 - Implementação dos Handlers 

O objetivo de hoje foi a implementação dos Handlers, que são as funções que fazem o bot reagir aos eventos do chat.

###  O que utilizei:
- **Handler de Início (@cl.on_chat_start):** Configurei a mensagem de boas-vindas que aparece assim que o chat é aberto.
- **Handler de Mensagem (@cl.on_message):** Estruturei a lógica para capturar o que o usuário digita e preparar a resposta.
- **Uso de Async/Await:** Apliquei programação assíncrona para garantir que a interface não trave durante as interações.
